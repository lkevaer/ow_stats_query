评分偏重最后一击与 Fleta，因此 T、C 更容易获得高分。任意位置最后一击占比≥50%时高权重加分；近12场至少7场 Fleta≥80%，标记 SMURF，给予最高权重的专项加分。S 从82分起。

完整评分参考（文字说明）
  • 最后一击、伤害和生存是主要参考。T兼顾输出与生存，最后一击占比达到30%额外加分；C侧重伤害与最后一击，占比达到40%额外加分；全位置占比达到50%时高权重加分。
  • 辅助同时考虑生存、治疗、伤害与助攻，伤害权重低于T、C。高Fleta加分逐渐加速；高阵亡明显扣分，需要足够高的进攻贡献补偿。
  • 阵亡结合实际时长、队内差距和双方整体阵亡量判断。全队阵亡明显较低时，所有位置降低扣分敏感度；辅助仅为全队最高，不自动重扣。例如队友阵亡2、3次，辅助4次，不触发最高阵亡重扣。
  • 队友普遍阵亡5次、辅助6至7次时，需要更明显扣分。全队高阵亡不能豁免辅助的生存要求，即使T、C都阵亡10次，辅助仍应争取更少阵亡。
  • 非极端碾压局中，对手阵亡明显更多、辅助只比队友多阵亡一次时，免除最高阵亡额外扣分；其他生存表现仍参与评分。
  • 败方高Fleta会减轻生存扣分；队友全为负战绩而本人正战绩时进一步照顾。补偿有上限，不无限抵消高阵亡。
  • 近12场至少7场Fleta达到80%为SMURF，给予综合评分中最高权重的专项加分。不足12场但已有7场达标也可确认，其余仍标记样本不足。
  • KD使用击杀/阵亡，达到10可小幅加分；有击杀且零阵亡显示∞，0击杀0阵亡显示未知。胜率仅小幅参考，平局计入分母；高Fleta败局会减轻胜率带来的扣分。两项均不主导评级。
  • MVP按当局完整十人的自定义评分比较，并列最高可以同时获得；十人数据不全时不判定。Fleta达到80%标记CARRY，败方超过80%同时标记SVP。多个标志可以并存，颜色依次优先MVP、SVP、CARRY。标志本身不额外加分。
  • 组队人数按本场组队成员记录显示，使用淡色标记；缺失或异常时显示组队未知，不推测人数。
  • 全队0-0-x、全队负战绩及明显碾压局，对胜负双方均降低本场汇总权重；短局也降权。伤害、治疗等数据按实际时长换算每10分钟比较，优先参考同位置队友。
  • 综合分按对局权重汇总后，参考持续高Fleta、胜率和KD。综合Fleta使用全部有效对局最后一击总数汇总，不直接平均各场百分比。Fleta仅表示个人最后一击÷（团队最后一击×50%），可以超过100%；零分母显示未知。
  • 只查询所选模式最近12场，休闲与竞技分开，不混入角斗领域。关键数据缺失不计分；不足12场显示实际场数并标记暂定。完整度表示样本及字段覆盖情况，不是评级正确率。
  • S从82分、A从75分、B从60分、C从45分起，其余D；SMURF是额外表现等级。以上均为自定义评分，并非网易官方分数或段位。
  • 上下等马只在本次名单内相对排序，同分同档，单人显示中等马，无数据不评级。评分不按段位修正对局含金量，名单段位差距过大时没有比较意义。
