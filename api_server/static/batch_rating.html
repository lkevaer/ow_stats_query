完整评分参考（文字说明）
  • 最后一击、伤害和生存是主要参考。T兼顾输出与生存，最后一击占比达到30%额外加分；C侧重伤害与最后一击，占比达到40%额外加分；全位置占比达到50%时高权重加分。
  • 辅助同时考虑生存、治疗、伤害与助攻，伤害权重低于T、C。Fleta达到35%增加进攻贡献加分，达到40%给予较高权重进攻加分，达到50%给予高权重加分且不触发高阵亡惩罚。这些门槛使用Fleta本身，分别相当于个人最后一击占比17.5%、20%和25%。
  • 阵亡结合实际时长、队内差距和自家整体阵亡量判断。全队阵亡明显较低时，所有位置降低扣分敏感度；辅助仅为全队最高，不自动重扣。例如队友阵亡2、3次，辅助4次，不触发最高阵亡重扣。
  • 辅助Fleta未达到50%时，阵亡额外扣分按实际时长和队内差距温和递增，不再因略多1至2次就叠加固定重扣；普通负荷通常不超过10分，只有阵亡率、相对差距、倍数与实际次数都明显突出时，才逐步接近15分的展示上限。15分只限制这项额外扣分，生存基础贡献仍另计；全队高阵亡不会自动豁免辅助的生存要求。
  • 辅助只比队友多阵亡一次时，免除最高阵亡额外扣分；其他生存表现仍参与评分。
  • 任意位置有有效贡献且零阵亡时，给予较高权重生存加分；其他队友阵亡越多奖励越高，短局按时长缩减。KD使用消灭÷max(阵亡,1)，零阵亡按1作分母，原始阵亡仍为0。
  • 完整已结束且至少6.5分钟、双方完整名单及关键统计齐全的对局中，辅助全场0伤害标记灰色BOT，评分最高25分并作最高权重下调。缺失伤害、短局、明确中退或参与时长不足不触发；不会将缺失数据当作0伤害。
  • 败方高Fleta会减轻生存扣分；队友全为负战绩而本人正战绩时进一步照顾。补偿有上限，不无限抵消高阵亡。
  • 近12场至少7场Fleta严格大于65%为SMURF，等于65%不计入，给予综合评分中最高权重的专项加分。不足12场但已有7场达标也可确认，其余仍标记样本不足。
  • 综合KD达到10可小幅加分；近12场至少9场KD达到7，给予较高权重加分。7消灭0阵亡的KD为7，1消灭0阵亡的KD为1，0消灭0阵亡的KD为0。
  • 通常胜率只小幅参考，平局计入分母；完整近12场至少10胜时，在胜率旁标记“手感火热”，并提高胜率加分权重。样本不足不推测完整12场胜率。高Fleta败局仍会减轻胜率扣分。
  • MVP按当局完整十人的自定义评分比较，并列最高可以同时获得；十人数据不全时不判定。Fleta达到80%标记CARRY，败方超过80%同时标记SVP。多个标志可以并存，颜色依次优先MVP、SVP、CARRY。标志本身不额外加分。
  • 组队人数按本场组队成员记录显示，使用淡色标记；缺失或异常时显示组队未知，不推测人数。
  • 小于6.5分钟的对局适当降权，越短权重越低；超过15分钟的对局小幅增权，有上限。双方最后一击总数几乎持平且数量充足时，较明显增权；缺失或全零不推测。败方最后一击不超过胜方四分之一，也视为碾压局；全队0-0-x、全队负战绩及明显碾压局均对双方降权，各项共同影响本场最终权重。
  • 伤害、治疗等数据按实际时长换算每10分钟比较，优先参考同位置队友。逐场按原来的独立列展示英雄、段位、地图、胜负和各项数据，支持横向滚动。权重合计可能超过实际场数，不代表增加了对局。
  • 综合分按对局权重汇总后，参考持续高Fleta、胜率和KD。综合Fleta使用全部有效对局最后一击总数汇总，不直接平均各场百分比。Fleta仅表示个人最后一击÷（团队最后一击×50%），可以超过100%；零分母显示未知。
  • 只查询所选模式最近12场，休闲与竞技分开，不混入角斗领域。关键数据缺失不计分；不足12场显示实际场数并标记暂定。完整度表示样本及字段覆盖情况，不是评级正确率。
  • 单局额外加分递减，胜方/平局单局最高99分、败方最高95分，不产生单局100/SSS。综合评分范围0至100，100分为SSS，S从90分、A从80分、B从70分、C从60分起，其余D；A级表示队内贡献较高，SMURF是额外表现等级。以上均为自定义评分，并非网易官方分数或段位。
  • 上下等马只在本次名单内相对排序，同分同档。只有一位有效评分玩家时不分上下等马，请输入更多ID以比较；无数据不评级。评分不按段位修正对局含金量，名单段位差距过大时没有比较意义。
